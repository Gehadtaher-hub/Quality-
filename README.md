# منصة خارطة طريق الاعتماد والجودة — الإصدار الثالث

نسخة تشغيلية أولية تعمل محليًا دون خادم.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` باستخدام Microsoft Edge أو Google Chrome.
3. تُحفظ البيانات محليًا في المتصفح.

## الوظائف
- لوحة جاهزية للمؤسسة والبرامج الأربعة.
- خارطة طريق لمدة 18 شهرًا.
- إضافة وحذف وتحديث حالة المهام.
- إضافة وحذف الأدلة.
- تصدير واستيراد نسخة احتياطية JSON.
- تصميم عربي RTL ومتجاوب.

## حدود النسخة
- لا تحتوي على حسابات مستخدمين أو قاعدة بيانات مركزية.
- لا ترفع ملفات الأدلة نفسها؛ بل تسجل بياناتها الوصفية.
- نسب الجاهزية الحالية تجريبية.

## الانتقال للإنتاج
يوصى في المرحلة التالية باستخدام ASP.NET Core أو Laravel، وقاعدة SQL Server أو PostgreSQL، وتكامل Microsoft Entra ID، وتخزين SharePoint/OneDrive للأدلة، وسجل تدقيق وصلاحيات مفصلة.
